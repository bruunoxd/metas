🎯 App de Metas Pessoais
Aplicativo criado com FlutterFlow e Supabase com o objetivo de gerenciar metas de forma visual, prática e eficiente. Acompanhe o progresso de seus objetivos com filtros, indicadores e status personalizados.

🧩 Funcionalidades
✅ Criar e editar metas

📊 Acompanhar progresso com indicadores de porcentagem

🔍 Filtrar metas por prioridade: ALTA, MÉDIA, BAIXA ou TODAS

🚦 Controle de status: Não iniciado, Iniciado, Concluído

🗓 Definir data de entrega

🎨 Interface responsiva e amigável com FlutterFlow

🛠 Tecnologias Utilizadas
FlutterFlow

Flutter

Supabase

Percent Indicator

Google Fonts

Provider

📦 Estrutura do App
HomePageWidget: exibe metas cadastradas com filtros e progresso

CriarMetaWidget: modal para adicionar nova meta

EditarMetaWidget: modal para atualizar metas existentes

Supabase tabelas:

Metas: título, descrição, prioridade, status, progresso, data de entrega

🚀 Como Usar
Clone o repositório:

git clone https://github.com/bruunoxd/app-de-metas.git
cd app-de-metas
Importe o projeto no FlutterFlow (ou abra no VS Code, se for exportado)

Configure as credenciais da Supabase (chave de API e URL do projeto)

Rode o app no seu emulador ou dispositivo físico
